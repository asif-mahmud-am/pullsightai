# PullSight AI 🧠✨

PullSight AI is an AI-Powered Pull Request Reviewer that automates and enhances the code review process using advanced Large Language Models. Whether you're working with GitHub, GitLab, or Bitbucket — PullSight provides intelligent, contextual feedback directly within your existing version control workflows to improve code quality and accelerate development cycles.

⚠️ This repository hosts the open-source edition. For advanced features like Stripe integration, team-level permissions, and proprietary agent templates, see the SaaS edition (coming soon).

## 🔧 Features

- 🧩 **Modular AI Agents** (Python-based)
- ⚙️ **Clean NestJS API Backend**
- 🌐 **Next.js Frontend** with Tailwind
- 🧠 **Prompt Orchestration, RAG, and More**
- 📦 **MongoDB** for scalable data handling

## 📦 Tech Stack

| Component | Tech              |
| --------- | ----------------- |
| Backend   | NestJS            |
| Frontend  | Next.js           |
| AI Agent  | Python, LangChain |
| Database  | MongoDB           |

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm/yarn
- Python 3.9+
- MongoDB (local or cloud)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/melioraweb/pullsightai.git
cd pullsightai
```
